# Each difference from that list is stated below.

# On web, the SDK removes the x-launchdarkly-tags header from streaming
# requests. The CORS allow-list of the LaunchDarkly streaming service does not
# include it, so a browser preflight with it fails. The stream tags tests
# expect the header, so they cannot pass. The default FDv2 data system
# streams, so the fallback directive test and the disallowed characters test
# fail the same way. The poll tags tests also fail this way, because the
# harness pairs the polling initializer with a streaming synchronizer for a
# JavaScript-kind SDK and checks the synchronizer request.
#
# The JS list also skips "streaming/fdv2/FDv1 fallback directive/directive
# without FDv1 fallback configured halts the data system". The Flutter SDK
# passes that test, so it is not listed here.
